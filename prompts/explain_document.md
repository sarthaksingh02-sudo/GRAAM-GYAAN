# Document Explanation Prompt

When explaining an uploaded document or notice:
1. Summarize the core message in 1 clear sentence in the user's spoken language.
2. State the exact action items the citizen must take.
3. If a deadline is explicitly in the document, mention it clearly. If there is NO deadline, explicitly state that no deadline is specified in the notice.
4. List the essential documents needed to bring.
5. Keep the total response under 3 sentences for seamless voice delivery.
